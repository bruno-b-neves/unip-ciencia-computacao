# Imagens dos circuitos

As 37 capturas foram extraídas do relatório de aulas práticas fornecido por Bruno Neves. Estão agrupadas conforme os cinco primeiros roteiros, com suas dimensões originais. As páginas indicadas nas legendas permitem localizar o registro no documento pessoal do autor.

Os diagramas SVG na pasta esquemas são ilustrações didáticas produzidas para o livro. Não são capturas de novas simulações no CircuitVerse. O PDF original e os endereços privados não integram o site.
