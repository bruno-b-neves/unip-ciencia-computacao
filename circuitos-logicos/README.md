## Um percurso visual pela lógica digital

Este livro reúne oito roteiros de Circuitos Lógicos Digitais: das portas básicas à construção de circuitos que codificam informações, acendem displays e realizam operações binárias. Cada capítulo combina explicações, tabelas-verdade e exemplos para acompanhar o comportamento dos sinais.

## Como usar este livro

Siga o sumário para estudar na ordem do roteiro, use a busca para localizar conceitos e clique nas imagens para ampliar os circuitos. Os laboratórios permitem alterar entradas e comparar os estados com as tabelas. Os modelos são combinacionais: mostram a função lógica, sem representar atrasos de propagação ou características elétricas.
