# Cadernos de Computação

Meus estudos em Ciência da Computação na UNIP, organizados em livros por disciplina. Este repositório reúne os relatórios, exercícios e códigos desenvolvidos ao longo dos semestres.

📚 **[Abrir a biblioteca de aprendizados](https://bruno-b-neves.github.io/unip-ciencia-computacao/)** — disponível após publicar o catálogo no GitHub Pages.

## Livros por semestre

### 1º semestre

- **[Circuitos Lógicos](circuitos-logicos/README.md):** oito roteiros com portas lógicas, Karnaugh, codificação e operações binárias, com imagens e laboratórios interativos.
- **[Introdução à Programação Estruturada](introducao-programacao-estruturada/README.md):** doze roteiros de Python, dos primeiros comandos ao SQLite.

### 2º semestre

- **[Banco de Dados](banco-de-dados/README.md):** oito roteiros de modelagem, consultas SQL, views, procedures e controle de acesso.
- **Programação Orientada a Objetos:** em preparação.

### 3º semestre

- **Prática de Programação Orientada a Objetos:** em preparação.
- **Linguagem de Banco de Dados:** em preparação.

No site, é possível buscar assuntos e filtrar os livros pelo semestre.

## Organização e publicação

Cada livro tem sua própria pasta, página inicial e navegação. O arquivo [`catalogo.json`](catalogo.json) registra as disciplinas e seus semestres. Um único fluxo do GitHub Actions publica o catálogo e todos os livros disponíveis.

Consulte o [guia de publicação e manutenção](COMO-PUBLICAR.md) para ativar o site, visualizar localmente ou acrescentar um livro.
